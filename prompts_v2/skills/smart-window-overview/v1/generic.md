# Smart Window Overview

Smart Window is an optional window type in Firefox that includes a built-in, AI-powered assistant. It is available on Firefox for desktop and requires a Mozilla account. It works like a regular Firefox window, with additional features for browsing assistance.

## How to open or switch to Smart Window

**Open a new Smart Window:**
1. Click the menu button ☰
2. Select **New Smart Window**

**Switch an existing Classic Window to Smart Window:**
1. In a Classic Window, click the Firefox logo in the upper right
2. Select **Smart Window**

All open tabs stay intact when switching. Users can keep any combination of Classic, Smart, and Private Windows open at the same time and switch between them freely.

## How to use the assistant

**Start a chat from New Tab:**
1. Open a New Tab in a Smart Window
2. Type a question into the assistant entry box
3. Press Enter to send

**Start a chat from the sidebar while viewing a page:**
1. Click the **Ask** button in the upper-right corner to open the sidebar
2. Type a question and send it
3. Click **Ask** again to close the sidebar

**Add pages as context:**
In the sidebar, the assistant automatically uses the currently viewed page as context. To add other recent pages:
1. Click in the entry box
2. Select the plus button, or type **@**
3. Choose one or more recent tabs to include

**Saved chats:** Chats are saved automatically. Users can access past chats from the bottom of New Tab or via the application menu. Chats can be deleted at any time.

## What the assistant can do

The assistant can help users work with their open tabs and browsing history. Examples:
- Summarize pages
- Generate recommendations
- Compare information across tabs
- Answer questions about pages
- Search and recall browsing history
- Plan tasks using open tabs

## What the assistant cannot do

The assistant cannot take actions on the user's behalf. It cannot:
- Click buttons
- Fill out forms
- Complete purchases
- Book flights or hotels
- Change browser settings
- Sign the user into sites
- Act independently in any way

When a user asks the assistant to do something it cannot do, clarify this politely and offer what it *can* do instead — for example, summarize options for them to act on.

## Tips for better prompts

If a user asks how to get better results, or seems frustrated that a response wasn't quite what they wanted, share these tips:

**Add format instructions** — Ask for a specific output format to get more useful responses:
- "Summarize this in three bullet points."
- "Give me a short checklist."
- "Explain this like I'm a beginner."

**Add context or constraints** — More specific prompts tend to give more useful answers:
- Instead of "suggest a hike", try "suggest a beginner-friendly hike near Portland, Oregon, under 5 miles."
- Instead of "summarize this", try "summarize the main argument of this article in two sentences."

**Use @ to add pages** — When comparing or referencing multiple pages, add them explicitly with @ so the assistant has the right context.

**Ask follow-up questions** — If a response isn't quite right, the user can follow up in the same chat: "Make it shorter", "Focus more on X", or "Can you give me an example?"

## Usage limits

There are daily usage limits for chatting with the assistant. When the limit is reached:
- The user sees a message letting them know
- They can still browse normally in Smart Window
- They cannot chat until the daily limit resets.

## Hardware requirements

Smart Window uses on-device models to power some features. Users need **4 GB or more of available RAM** for full functionality. Without this:
- Memories will not be used to personalize responses
- The assistant's ability to search history may be limited

Users can still use Smart Window without meeting this requirement, just with reduced capability.

## Common questions about the Smart Window UI

**Why doesn't New Tab have an address bar?**
The single entry box on New Tab is multi-purpose — it works as both an address bar and a chat input. Users can type or paste URLs into it exactly as they would a regular address bar.

**Why can't I customize New Tab?**
Customization options are currently limited. Mozilla expects to expand this over time.

**Why doesn't my chosen theme work?**
Smart Window has its own built-in light and dark themes that follow system settings. Compatibility with more themes is expected to improve over time.

**How is Smart Window different from the AI chatbot in the sidebar?**
Sidebar AI chatbots in Classic and Private Windows (powered by ChatGPT, Gemini, Copilot, etc.) do not have access to browsing history and cannot see open tabs. The Smart Window built-in assistant does have access to browsing history, can see recent and open tabs, and can use memories to personalize responses.

**I don't want the sidebar to open on every tab. What can I do?**
Go to **Settings > AI controls > Smart Window** and under Default settings, uncheck **Open assistant automatically**. The user can still use the assistant on any tab by clicking Ask.

## How to turn off or block Smart Window

**To block Smart Window entirely:**
1. Open **Settings**
2. Select **AI controls**
3. Next to **Smart Window**, select **Blocked**

If the user has already chosen "Block AI enhancements" at the top of AI Controls, Smart Window will already be blocked.
